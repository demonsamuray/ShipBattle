# Reference images

This folder contains supplied source images used for visual comparison and audit notes. Runtime code uses the optimized assets under `assets/png/default/`; these reference images are not loaded by the game.

- `ilha.png` is the source silhouette referenced by the documented collision-mask sampling.
- `Ilhasub.png` is a related island reference image.
- `tile-contact-all.png` is the contact sheet for the 96 numbered tile PNGs.

The original distribution and license terms for the supplied art have not been confirmed in this checkout. See `THIRD_PARTY_NOTICES.md` before redistributing the artwork.
